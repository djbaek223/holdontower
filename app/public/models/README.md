# 3D 모델 (GLB)

지금 들어 있는 파일은 `npm run models`(`tools/build-models.mjs`)가 코드로 만든 기본 모델이다.
Blender, AI 이미지→3D 도구 등으로 만든 모델로 바꾸려면 **같은 파일 이름으로 덮어쓰고** 아래 규칙을 지키면 된다.
교체 후 `http://localhost:5173/?viewer` 에서 크기·방향·색·걷기 동작을 확인한다.

> `npm run models`를 다시 실행하면 이 폴더의 4개 파일을 기본 모델로 덮어쓴다. 직접 만든 모델을 넣었다면 실행하지 않는다.

## 공통 규칙

| 항목 | 규칙 |
| --- | --- |
| 형식 | `.glb` (glTF 바이너리), Draco 압축 사용 안 함 |
| 단위·방향 | 1 = 1m 기준, 위쪽 +Y, **정면 +Z** |
| 원점 | 바닥 중앙 (발바닥, 나무 밑동, 기둥 밑) |
| 색 | 정점 색(COLOR_0) 권장. 앱이 단색 Lambert 재질로 바꿔 그리므로 텍스처·PBR 질감은 반영되지 않는다 |
| 용량 | 파일당 300KB 이하 권장 (모바일 초기 로딩) |
| 저작권 | 오리지널 또는 CC0만. 기존 게임 캐릭터를 따라 하지 않는다 (PRD 8장) |

## character.glb

블록형 꼬마 캐릭터 (약 2.3등신, 큰 정육면체 머리).

| 항목 | 규칙 |
| --- | --- |
| 크기 | 키 약 2.2 (앱에서 1.5배로 키워 그림) |
| 노드 이름 | `LegL`, `LegR` (엉덩이 위치가 피벗), `ArmL`, `ArmR` (어깨 위치가 피벗). 앱이 X축으로 회전시켜 걷기 동작을 만든다 |
| 모자 노드 | `Cap` 노드는 앱이 사람마다 보이거나 숨긴다 (없어도 된다) |
| 재질 이름 | `Jacket`(셔츠), `Hair`(머리카락), `Cap`(모자) 재질은 앱이 사람마다 다른 색으로 칠한다. 나머지는 정점 색 |
| 뼈대(스킨) | 지금은 쓰지 않는다. 뼈대·애니메이션 클립이 있는 모델을 쓰려면 앱 코드 수정이 필요하다 |

내 캐릭터는 노란 셔츠·검은 머리·모자 없음으로 고정(`PLAYER_LOOK`), 주민은 이름에 따라 셔츠색·머리색·모자가 정해진다(`lookFor`, `src/scene/Player.tsx`).
노드 이름이 하나라도 없으면 캐릭터는 보이지만 걷기 동작이 멈춘다. 파일을 못 읽으면 같은 모양의 박스 캐릭터로 대신 보인다.

## tree.glb · lamp.glb · planter.glb (소품)

- **메시 1개**로 합쳐서 만든다. 앱이 첫 번째 메시만 가져와 여러 곳에 인스턴싱으로 그린다 (드로우콜 1개).
- `lamp.glb`는 가로등 팔이 **+Z** 방향을 향하게 만든다 (앱이 도로 쪽으로 돌려 놓는다).
- 크기 기준: 나무 키 약 4.5, 가로등 높이 약 4.7, 화분 폭 약 1.8.
